# 🧪 MolFusion

Multi-Agent Molecular Feature Extraction Framework Suite. Easily process datasets of SMILES strings, visualize structural mappings, and compile high-dimensional matrix features instantly in your browser.

## 🌐 Live Application
You can use the fully operational web app directly here:
👉 **[Launch MolFusion Live Web Suite](https://omidmah.github.io/MolFusion/)**

---

## 📋 Features
* **Global Dataset Processing:** Upload custom `.csv` files and calculate properties for all SMILES concurrently.
* **Dual-Matrix Output:** 1. **File 1:** Structural Physicochemical core properties matrix.
  2. **File 2:** High-Dimensional multi-agent vector feature matrix.
* **High-Res Visual Exports:** Save high-quality 2D structure layout mappings as PNGs instantly.
